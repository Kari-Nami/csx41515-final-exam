# Triple Threat Arcade

Triple Threat Arcade combines three small Unity games into one project with a shared Main Menu and pause system.

## Game flow

Launch the project into **Main Menu**, select one of the three games, and press **Esc** while playing to Resume, Restart, or return to the Main Menu.

## Included games

- **Mad Driver:** Drive along an obstacle-filled road while avoiding traffic and switching camera views.
- **Fly Like a Bird:** Pilot a plane through an obstacle course with unrestricted looping and inverted flight.
- **I'm a Sumo and a Ball:** Control a ball, collect power-ups, and knock enemies off the arena.

## Requirements

- Unity Editor **6000.5.3f1**
- Unity Hub is recommended

## Run locally

1. Clone or download this repository.
2. In Unity Hub, select **Add project from disk** and choose this project folder.
3. Open the project with Unity `6000.5.3f1`.
4. Open `Assets/Scenes/MainMenu.unity` and press **Play**.
